STEP 0 — INSTALL REQUIREMENTS (One time only)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Install these on your computer FIRST:

1. Docker Desktop
   Download: https://www.docker.com/products/docker-desktop/
   ✅ This installs both Docker and Docker Compose

2. Git (optional but recommended)
   Download: https://git-scm.com/

3. Make (for Windows users only)
   Windows: Install via https://chocolatey.org/
   Run:     choco install make
   
   Mac/Linux: make is already installed ✅


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 1 — GET GROQ API KEY (Free)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Go to: https://console.groq.com/
2. Sign up (free)
3. Click "API Keys" → "Create API Key"
4. Copy the key (looks like: gsk_xxxxxxxxxxxx)

You need this in Step 3.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 2 — EXTRACT AND OPEN PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Download the ZIP file: smart-drug-interactions.zip
2. Extract it anywhere (e.g. Desktop)
3. Open your Terminal:
   - Windows: Search "Command Prompt" or "PowerShell"
   - Mac:     Search "Terminal"
   - Linux:   Ctrl + Alt + T

4. Navigate into the project folder:

   cd Desktop/smart-drug-interactions

   (change "Desktop" to wherever you extracted it)


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 3 — ADD YOUR GROQ API KEY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open the file called ".env" in any text editor (Notepad, VS Code).

Find this line:
   GROQ_API_KEY=your_groq_api_key_here

Replace with your real key:
   GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxx

Save the file.

NOTE: The .env file already exists in the project.
      Do NOT rename it. Do NOT delete it.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 4 — START DOCKER DESKTOP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Docker Desktop app on your computer.
Wait until you see "Docker is running" (green icon).

IMPORTANT: Docker must be running before Step 5.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
STEP 5 — BUILD AND RUN THE PROJECT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

In your terminal (inside the project folder), run:

   docker-compose up --build

This will:
  ✅ Download all required images
  ✅ Build backend (FastAPI + ML + RAG)
  ✅ Build frontend (React)
  ✅ Start PostgreSQL database
  ✅ Start Redis cache
  
  ✅ Start Kafka producers and consumers
  ✅ Start Prometheus + Grafana monitoring

⏳ First time takes 5-10 minutes (downloading images).
⏳ After that, starts in under 1 minute.

You will see lots of logs. That is normal.
Wait until you see:
   "drug_backend | ✅ Platform ready to serve requests"

STOP / RESTART COMMANDS (run in terminal)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Stop the project:
   docker-compose down

Start again (without rebuilding):
   docker-compose up

Rebuild everything fresh:
   docker-compose up --build

Delete all data and start fresh:
   docker-compose down -v

View logs of one service:
   docker-compose logs -f backend
   docker-compose logs -f frontend
   docker-compose logs -f kafka

COMMON ERRORS AND FIXES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

ERROR: "Cannot connect to Docker daemon"
FIX:   Open Docker Desktop first, wait for green icon

ERROR: "Port 3000 already in use"
FIX:   Run: docker-compose down
       Then: docker-compose up --build

ERROR: "GROQ API error"
FIX:   Check your GROQ_API_KEY in .env file
       Make sure no extra spaces around the key

ERROR: Backend keeps restarting
FIX:   Run: docker-compose logs -f backend
       Check error message and fix .env values

ERROR: Kafka topics not found
FIX:   Wait 30 seconds after startup — Kafka needs time
       Or run: docker-compose restart kafka-init
